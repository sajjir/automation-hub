# 🚀 Automation Hub (WordPress & n8n Bridge Pro) — Node.js & React Edition

**Automation Hub** یک سیستم هسته مرکزی و هوشمند برای یکپارچه‌سازی و اتصال رویدادهای ووکامرس، فرم‌های تماس و کاربران به پلتفرم‌های **n8n**، **تلگرام (Telegram Bot)** و **سامانه‌های پیامکی (SMS Panels)** با موتور سناریوساز پیشرفته، صف‌بندی غیرهمزمان (Async Queue)، احراز هویت پیامکی (OTP) و شبیه‌ساز زنده است.

این پروژه از افزونه وردپرس به صورت فول‌استک با **Node.js (Express)** و **React SPA (Vite)** با وفاداری کامل به منطق بیزنس و طراحی بصری اصلی بازنویسی شده است.

---

## ⚙️ امکانات پیاده‌سازی شده

### ۱. موتور سناریوساز داینامیک (Rules Engine)
- تعریف بی‌نهایت سناریو بر اساس تریگرهای متنوع:
  - تغییر وضعیت سفارشات ووکامرس (Processing, Completed, On-Hold, Pending, Cancelled, ...)
  - ثبت سفارش جدید
  - ثبت فرم تماس (Contact Form 7)
  - ثبت‌نام کاربر جدید
  - درخواست احراز هویت پیامکی (OTP)
- سیستم شرط‌های منطقی داینامیک (AND / OR) با متغیرهای:
  - جمع کل مبلغ سفارش (`total`)
  - شهر صورت‌حساب (`billing_city`)
  - وضعیت سفارش (`status`)
  - نقش کاربر (`user_role`)
- عملگرهای شرطی: `==`، `!=`، `>`، `<`، `contains`، `not_contains`
- اکشن‌های چندگانه در هر سناریو:
  - ارسال پیامک (SMS)
  - ارسال تلگرام (Telegram Bot)
  - ارسال وب‌هوک (n8n Webhook)
  - ارسال ایمیل (Email)
- سیستم تاخیر و زمان‌بندی (آنی، بر حسب دقیقه، ساعت یا روز)
- پارسر تگ‌های پویا و شورت‌کدها: `{order_id}`، `{status}`، `{date}`، `{time}`، `{full_name}`، `{phone}`، `{total}`، `{items_summary}`، `{otp}`

### ۲. مدیریت کانال‌ها و اتصالات (Connections)
- مدیریت وب‌هوک‌های n8n، پنل‌های پیامکی و توکن ربات‌های تلگرام
- تست اتصال زنده (Live Test Connection ⚡) برای اعتبارسنجی آنی کانال‌ها
- تنظیم پروکسی تلگرام برای محیط‌های دارای محدودیت

### ۳. صف اجرای غیرهمزمان (Queue System)
- مدیریت صف با وضعیت‌های `pending`، `processing`، `completed`، `failed`، `cancelled`
- پردازش پس‌زمینه با ارزیابی مجدد شرط‌ها قبل از اجرای وظایف تاخیری
- امکان تلاش مجدد (Retry) برای پیام‌های ناموفق یا لغو وظایف در انتظار

### ۴. سیستم احراز هویت پیامکی (OTP Auth)
- فرم احراز هویت یکپارچه (تایید شماره تلفن ایران، کد اعتبارسنجی ۴ رقمی، تایمر ۲ دقیقه‌ای و ارسال مجدد)
- فرم تکمیل مشخصات (نام، نام‌خانوادگی، ایمیل) برای کاربران جدید
- اتصال خودکار سفارشات مهمان به حساب کاربری

### ۵. لاگ‌برداری دقیق و رهگیری رویدادها (Debug Logger)
- ثبت جزئیات دقیق اجرای Bridge، Queue، Sender و کانتکست جیسون
- فیلتر بر اساس سطح لاگ (اطلاعات، موفقیت، هشدار، خطا) و پاکسازی آسان

### ۶. شبیه‌ساز و تستر زنده رویدادها (Live Event Dispatcher)
- شبیه‌سازی انواع سفارشات با مقادیر دلخواه و تست آنی منطبق شدن سناریوها و ارسال به کانال‌ها

## 🛠️ راه‌اندازی و اجرا

```bash
# نصب وابستگی‌ها

# اجرای حالت توسعه (پورت 3000)
npm run dev

# بیلد نسخه نهایی
npm run build

# اجرای سرور پروداکشن
npm start
```
